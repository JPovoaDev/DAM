# 01 Visão Geral

## Objetivo
O objetivo desta aplicação é proporcionar uma experiência Android simples e agradável para utilizadores que queiram ver imagens aleatórias de cães. A app vai buscar imagens de alta qualidade à Dog API e apresenta-as no ecrã.

## Utilizadores Alvo
- **Amantes de Cães:** Qualquer pessoa que goste de ver fotos de cães.
- **Utilizadores Casuais:** Pessoas que procurem uma aplicação rápida para animar o dia.

## Comportamento Geral do Sistema
- **Recolha de Dados:** A aplicação faz pedidos de rede à Dog API para obter os recursos das imagens.
- **Visualização:** As imagens recebidas são processadas e apresentadas de forma assíncrona no ecrã.
- **Interação do Utilizador:** Os utilizadores podem facilmente pedir para carregar novas imagens.
- **Gestão de Erros:** O sistema lida com erros comuns de rede de forma robusta, garantindo uma boa experiência mesmo que o carregamento de uma imagem falhe.
